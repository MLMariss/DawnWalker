# Icon reference set

The game's own perk icons, uploaded as **visual reference** for authoring the
planner's marks. Nothing here is served by the site and nothing here is
published: the board renders `assets/icons.js`. Pull this folder back out of the
repo once the marks are drawn — the artwork is Rebel Wolves', and GitHub Pages
would otherwise serve it.

63 files, covering all 54 perks and all 9 ultimates. The 27 abilities have no
files yet.

Filenames match the registry name after stripping `T_Icon_Perk_`, except these
five, which are the game's internal spellings:

| File | Node | Registry name |
| --- | --- | --- |
| `T_Icon_Perk_universalBlock.webp` | S1 | Omniblock |
| `T_Icon_Perk_Vigor.webp` | S4 | Vigour |
| `T_Icon_Perk_Parry.webp` | S6 | Perfect Block |
| `T_Icon_Perk_FatesFavor.webp` | S7 | Fate's Favour |
| `T_Icon_Perk_HexMastery.webp` | W4 | Witchcraft Mastery |

`T_Icon_Perk_AetherCascade.webp` matches the Witchcraft ultimate through its
registry `alias`; the planner calls it Arcane Cascade.
